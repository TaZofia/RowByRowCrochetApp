Wymagania sprzętowe:

1. Urządzenie docelowe: Smartfon lub tablet z systemem operacyjnym Android 7.0

2. Pamięć: 30 MB

Uruchomienie projektu w środowisku deweloperskim

1. Wymagane są:

  - Środowisko: Android Studio lub Intellij IDEA z wtyczką Android,

  - Narzędzia: JDK w wersji 21, Android SDK w wersji 37.

2. Należy sklonować repozytorium za pomocą:

    git clone https://github.com/TaZofia/RowByRowCrochetApp.git}

3. Następnie należy otworzyć katalog projektu w IDE, podłączyć fizyczne urządzenie z włączoną opcją "Debugowanie USB" i uruchomić aplikację.

Pobranie i zainstalowanie aplikacji

1. Przejść do zakładki Releases

2. Z najnowszej wersji z sekcji Assets należy pobrać plik app-release.apk. Gdy wyświetli się komunikat bezpieczeństwa wybrać opcję "Pobierz mimo to".

4. Otworzyć pobrany plik i jeśli pojawi się ostrzeżenie Google Play Protect, rozwinąć opcję "Więcej szczegółów" i kliknąć "Zainstaluj bez skanowania".

5. Aplikacja powinna być gotowa do użycia.
